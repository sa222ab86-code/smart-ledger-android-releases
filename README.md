# الدفتر الذكي — أندرويد (ملفات التحديث)

هذا المستودع للتوزيع فقط: ملفات تثبيت التطبيق وملف التحديث، ولا يحتوي كوداً.
يُنشر فيه تلقائياً من مستودع الكود الخاص عبر GitHub Actions مع كل إصدار جديد.

| الملف | الوصف |
|---|---|
| `SmartLedger-<الإصدار>.apk` | ملف التثبيت الموقّع — للتوزيع المباشر على العملاء |
| `SmartLedger-<الإصدار>.aab` | حزمة متجر جوجل |
| `latest-android.json` | معلومات آخر إصدار — **يقرؤها التطبيق للتحديث التلقائي** |

## مهم: يجب أن يبقى هذا المستودع عاماً (Public)

التطبيق يفحص التحديث بلا تسجيل دخول من الرابط الثابت:

```
https://github.com/sa222ab86-code/smart-ledger-android-releases/releases/latest/download/latest-android.json
```

فإن صار المستودع خاصاً توقّف التحديث التلقائي عند كل العملاء. (نفس مبدأ
`smart-ledger-releases` في نسخة الويندوز.)

## التثبيت على الجهاز

1. افتح صفحة **Releases** أعلاه ونزّل ملف `.apk` من آخر إصدار.
2. افتح الملف في الهاتف واسمح بـ«التثبيت من مصادر غير معروفة» عند السؤال.
3. يُثبَّت فوق النسخة السابقة وتبقى البيانات والترخيص كما هي.

بعد ذلك يتولّى التطبيق التحديث بنفسه: يفحص عند التشغيل وكل أربع ساعات، وينزّل
التحديث بالخلفية، ويظهر زر «التثبيت» في أسفل الشاشة.
